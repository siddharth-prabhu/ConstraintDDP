# Differential dynamic programming with stagewise equality and inequality constraints using interior point method

## Overview

This project is based on our paper (https://arxiv.org/abs/2409.12048)

## Features

- Stagewise equality and inequality constraint DDP in JAX

## Installation

Clone the repository:

```
git clone https://github.com/siddharth-prabhu/ConstraintDDP.git
cd ConstraintDDP

# Run CSTR example
python ilqr_examples.py --skip_cstr 0
```
